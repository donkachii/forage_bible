# Foredge brand assets

Created with built-in image generation. Exact prompts: generation-prompts.json.

- logo.png — transparent primary wordmark
- mark.png — transparent standalone mark
- favicon.ico — 16, 32, 48 pixel icon bundle
- icon-16/32/48/180/192/512.png — browser and app icons, vellum background
- social-og.jpg — 1200 × 630 link preview
- social-x.jpg — 1200 × 600 wide card
- social-square.jpg — 1080 × 1080 social post
- social-story.jpg — 1080 × 1920 story

App icon, Apple touch icon and Open Graph/X images are connected through Next.js file conventions in app/. Original app/favicon.ico retained; new browser icon supplied by app/icon.png. Set the production metadataBase to your real site URL when deploying outside Vercel.
